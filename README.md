A tiny chess engine in under 4 KB of Python: 0x88 board, alpha-beta search with quiescence, a transposition table, MVV-LVA move ordering and piece-square evaluation. It plays the make.fun tiny-chess-01 house gauntlet through the env, one move at a time, to a fixed node budget per move.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
